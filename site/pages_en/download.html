How to install

macOS

  1. Open the downloaded file and drag Vikey into Applications.
  2. Quit OpenKey, EVKey or any other Vietnamese input method.
  3. Open Vikey and allow Accessibility when asked.

SHA-256: SHA256

Windows

  1. Open the downloaded file. No admin rights needed.
  2. Quit OpenKey, EVKey, UniKey or any other Vietnamese input method.
  3. Vikey sits in the system tray. Press Alt+Z to switch languages.

If SmartScreen asks, click "More info", then "Run anyway".

Portable, no installer: x64 (zip) · ARM64 (zip)
SHA-256: WIN_X64_SHA (x64) · WIN_ARM64_SHA (ARM64)

Linux

  1. Install the package: sudo apt install ./vikey_*.deb (or sudo dnf install ./vikey-*.rpm, or sudo pacman -U ./vikey-*.pkg.tar.zst), then log out and back in.
  2. Open Settings › Keyboard › Input Sources and add "Vietnamese (Vikey)".
  3. Switch to Vikey with Super+Space. Press Alt+Z to switch English/Vietnamese.

Per-website memory is not available on Linux yet; per-app memory works for X11 apps on Wayland.
